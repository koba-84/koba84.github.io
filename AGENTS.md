# Instructions for this website

This repository contains Ryoma Kobayashi's personal website, built with Jekyll and al-folio.

- Treat `_pages/about.md`, `_config.yml`, and `_data/` as the source of public profile information. Do not invent biographical details or publish private contact information.
- Keep publications, projects, work history, and contact details empty unless Ryoma provides or confirms them.
- Keep al-folio runtime behavior in its versioned gems. Customize site metadata and content in this repository.
- Preserve the original MIT license and attribution when changing the starter.
